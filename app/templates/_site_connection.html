UniFi Access
How do I get a token?
  1. In the UniFi Access app, go to Settings → General → Advanced → API Token.
  2. Give it these permissions:
    • Locations Edit
    • Device View
    • System Log View
    • People & Groups View
    • Access Policy View
    • Visitor Edit · for visitor passes
  3. Copy it straight away. UniFi only shows it once.

It must be an Access token. A UniFi OS / Control Plane key won't work here.

Leave off unless you've put a real certificate on the console.
Cameras · optional
How do I get a Protect key?
  1. In UniFi OS, go to Settings → Control Plane → Integrations → Create API Key.
  2. Paste it here. OpnDoor only uses it to show camera pictures and video.

This one is a UniFi OS key, not the Access token.

UniFi Network · optional

UniFi Access sometimes reports a device's online state wrong. With this, the Devices page, alerts and reports ask UniFi Network instead (it knows what's connected, and shows each device's IP).

How do I get a key?
  1. On the console that runs UniFi Network (often your gateway), open UniFi OS: Settings → Control Plane → Integrations → Create API Key.
  2. Paste it here. OpnDoor only reads the list of connected devices with it.

If that console is also where UniFi Protect runs and you already pasted a Protect key, you can leave this blank.
